# Sessions

A session is a real `claude` or `cursor-agent` process running in a terminal inside the app.

You are usually the bottleneck when several sessions run at once. These pages are ordered from starting one to understanding what all of them are doing.

- [Start and manage sessions](start-and-manage-sessions.md) — start, work in the terminal, give a session a browser, stop, resume, remove.
- [Read a session's state](read-session-state.md) — Pergunta, Trabalhando, Ocioso, Fechado; context, cost and what a session is using.
- [Watch sessions running outside the app](watch-external-sessions.md) — observe or take over sessions started in other terminals.
- [Session notifications](session-notifications.md) — notifications, Dock badge, inline answer.
- [Session history and cost](session-history-and-cost.md) — past sessions, filters, cost, model prices.
