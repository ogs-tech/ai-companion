## Notifications

In **Settings → Sessões** (defaults in brackets):

- Notify when a session goes to Pergunta [on], when a turn over 2 minutes finishes [off], when the cost
  crosses US$ 5 and US$ 10 [off], and once when context passes 90% [on].
- Include external sessions [on]; stay quiet for the session whose tab you are looking at [on]; count
  Pergunta sessions on the Dock badge [on].
- **Responder pedidos de permissão direto da lista** [off] — expands a Pergunta row with the full command
  and working directory and offers *Permitir uma vez* / *Negar*. Only for sessions the app started, and
  only for permission prompts. It falls back to the CLI's own prompt if the answer is not delivered in
  time.
