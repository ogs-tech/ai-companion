# Source control

Review, commit and sync the Git repositories of your workspace.

In a multi-folder workspace each folder is its own repository.

- [Use the Git panel](use-the-git-panel.md) — review, stage, commit (with an AI-drafted message), push and pull.
- [Connect GitHub](connect-github.md) — store a token so the app can reach private repositories.
