Enter confirma, Esc cancela. Ao renomear, só o nome (sem a extensão) vem selecionado. Nome inválido ou já usado mostra a mensagem logo abaixo do campo, sem diálogo. Abas abertas do arquivo seguem para o caminho novo, sem perder alterações.

Como excluir?

O spec manda o arquivo para a lixeira do sistema, então ele é sempre recuperável pelo Finder.
