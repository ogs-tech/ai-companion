Explorer: projeto solo e ícones de arquivo

Duas decisões. Clique em uma opção em cada bloco e depois me conte o que achou no terminal.

1. Como identificar o projeto quando há uma pasta só?

Hoje a árvore começa direto em src/, docs/… sem dizer de qual projeto são.

A

Nó raiz na árvore recomendado

Mesma linha que já existe no multi-pasta: a pasta é o nó de topo, expandido, e os arquivos ficam dentro. Uma pasta é só o caso N=1 de várias, sem regra especial.

ai-companion main
src
main
renderer
docs
package.json
README.md
B

Cabeçalho fixo acima da árvore

O projeto vira um título (nome, caminho, branch) que não recolhe. A árvore começa logo abaixo, com menos indentação. Mais informativo, mas é um caso à parte do multi-pasta.

ai-companion~/Projects/ogs-tech/engine main
src
main
renderer
docs
package.json
README.md
C

Só no título do painel

A árvore não muda. O cabeçalho do painel Arquivos mostra “Arquivos · ai-companion”. É a menor mudança, mas o projeto some quando a árvore rola ou o painel fica estreito.

Arquivos · ai-companion
src
main
renderer
docs
package.json
README.md

2. Ícones por tipo de arquivo

Hoje todo arquivo usa o mesmo ícone genérico. Cada opção aparece no tema claro e no escuro.

A

Glifos por categoria, monocromáticos recomendado

Código, JSON, texto e imagem têm formas diferentes (Lucide, que o app já usa), todas na cor neutra. Segue “um papel cromático por vez”: o azul fica para ação e a cor fica para o status do Git. Sem dependência nova.

Claro
theme.ts
package.json
README.md
logo.png
.gitignore
Escuro
theme.ts
package.json
README.md
logo.png
.gitignore
B

Glifos com cor por categoria

Mesmos glifos, com um tom por categoria tirado dos papéis do design system. Identifica mais rápido pela cor, mas compete com os marcadores do Git (M, A, ?) que também usam cor.

Escuro

.gitignore
C

Pacote de ícones de IDE (ex.: Material Icon Theme)

Logos reais por linguagem e por arquivo conhecido (package.json, tsconfig…), como no VS Code. É o mais reconhecível, mas é uma dependência nova, coloridíssima, e foge do estilo traço fino do app. Não desenhei aqui porque dependeria do pacote.
